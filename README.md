# ft_printf

ft_printf is a project developed as part of the 42 curriculum that consists of
recreating the standard C `printf()` function.
The goal is to implement formatted output by handling different data types, format specifiers,
and conversion rules, including characters, strings, integers, hexadecimal values, and pointers.
This project strengthens understanding of variadic functions, format parsing, type conversions,
and output management in C.

**Technologies:** C, Variadic Functions, Makefile, Git.
